Cancellation & Return Policy

Simple and transparent process. Please read eligibility rules before requesting.

Cancellation

  • You can request cancellation before the order is dispatched.
  • Once dispatched, cancellation may not be possible; you can use return options if eligible.

Return Eligibility

  • Item must be unused, unwashed, and in original packaging with tags intact.
  • Return request must be placed within the return window mentioned on the product page or invoice.
  • Items marked as “Final Sale” may not be returnable if stated.

Wrong / Damaged Item

  • Contact support as soon as possible with unboxing photos/video.
  • After verification, we will arrange a replacement/return based on availability.

Refunds

  • Refund method depends on your payment method.
  • Processing time varies depending on banks/payment gateways.

Exchange

Exchange depends on stock availability. If the requested size/color is unavailable, we’ll suggest an alternative solution.

Keep the invoice and packaging intact until the return/exchange process is completed.
